# FinTechWallet-frontend

## Как открыть проект локально

1. Установите Node.js, если он еще не установлен.

2. Перейдите в папку проекта:

```bash
cd FinTechWallet-frontend
```

3. Установите зависимости:

```bash
npm install
```

4. Запустите проект в режиме разработки:

```bash
npm run dev
```

5. Откройте в браузере адрес, который появится в терминале. Обычно это:

```text
http://localhost:5174
```

## Полезные команды

```bash
npm run build
```

Собирает проект для продакшена.

```bash
npm run preview
```

Запускает локальный просмотр продакшен-сборки.

```bash
npm run lint
```

Проверяет код линтером.
